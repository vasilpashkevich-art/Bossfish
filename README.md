# Bossfish / «Малёк»

Браузерная игра про рыбу: появляешься мальком, ешь и растёшь до 50 уровня. От того, что ешь, рыба становится травоядной, всеядной или хищником, как в Spore. Каждые 5 уровней — эволюция, которая меняет облик: броня, огромная пасть, торпедный аппарат, ракетный ускоритель и т.д. Вокруг 52 рыбы-бота, которые живут по тем же правилам, что и игрок.

Вся игра — один HTML-файл без зависимостей: исходник в `src/game.html`, готовая страница в `index.html`.

## Как запустить

Онлайн: https://vasilpashkevich-art.github.io/Bossfish/ (после включения GitHub Pages).

Локально: открыть `index.html` в браузере. Работает на компьютере и на телефоне.

## Управление

| Клавиша | Действие |
|---|---|
| Мышь / стрелки / WASD | Плыть |
| Пробел / левая кнопка | Рывок (хищник с 4 уровня или эволюция «Ракетный ускоритель») |
| E / правая кнопка | Торпеда |
| Q | Электрический разряд |
| R | Облако чернил |
| F | Включить пузырь-усилитель |
| 1, 2, 3 | Выбор эволюции |
| Esc / P | Пауза: продолжить, справка, выйти в меню с сохранением |
| M | Звук вкл/выкл (громкость — в меню паузы) |
| H | Справка (игра на паузе) |

**На телефоне:** палец в любом месте экрана — джойстик; большая кнопка справа — рывок (или касание вторым пальцем); маленькие кнопки над ней — торпеда, разряд, чернила и пузырь-усилитель; кнопка с двумя полосками вверху — пауза.

## Что есть в игре

- **Еда.** Зелёное (водоросли, плоды, шары, саргассовые плоты) и красное (жучки, креветки, стайки мальков, крабы, медузы, кальмары). Крупная еда открывается с ростом.
- **Пути.** Травоядная (шипы с 4 уровня), всеядная, хищник (рывок с 4 уровня).
- **21 эволюция.** Каждая видна на рыбе. Среди новых: хвост-хлыст, присоска-прилипала, глазчатые пятна, ядовитые зубы, хамелеон, двойной рывок.
- **Отпор крупным.** Укус за хвост: мелкая рыба, догнав крупную сзади, отрывает кусок роста и на секунду её замедляет. Боты так же охотятся на рыбу в короне.
- **Пузыри-усилители.** 8 светящихся пузырей в толще воды: щит, скорость, невидимость, магнит для еды. Держать можно один, включать клавишей F.
- **Погоня.** Рывок 1,8× (с ускорителем 2,2×). Боты перед рывком на 0,3 с краснеют, крупная рыба на рывке плохо поворачивает и проносится мимо. Во время выбора эволюции и 2 с после рыба неуязвима.
- **Опасности.** Хищники, голод, сети рыбаков (ловят только крупных), жгучие медузы. С 30 уровня гигант понемногу теряет рост, если мало ест.
- **Сохранение.** Одиночная игра сохраняется сама каждые 10 секунд, при паузе и при закрытии вкладки (в браузере игрока). В меню — «Продолжить». Сохранение стирается, когда рыбу съедают.
- **Меню.** Одиночная игра, Продолжить, Сетевая игра (пока заглушка «в разработке»).
- **Звук.** Всё синтезируется в браузере (Web Audio), без файлов: подводный фон, бульки, звуки еды, рывка, умений, уровней, сердцебиение при погоне, гул сети.
- **Укрытия.** Гроты, коралловые арки и обломки лодок на дне, а выше — пещеры в скалах-столбах, гигантские раковины на уступах и пробоины в кораблях, стоящих носом вверх; внутри не видно и не достать тем, кто крупнее входа.
- **Языки.** Русский и английский: выбираются по языку браузера, переключаются кнопкой в меню и в паузе.
- **Монеты и скины.** Монеты за каждый раунд (уровень² × 0,6 + 4 в минуту + 3 за рыбу) и бонусы за первый рекорд 10/20/30/40/50 уровня (100/300/600/1000/2000). Магазин: Клоун 300, Тигровая 600, Неон 1000, Золотая 1800, Радужная 3000. Часть ботов тоже в скинах.
- **Обучение.** В первой игре стрелки и подсветка показывают еду, укрытие и опасность. Повторить — из справки.
- **Графика.** Авто / высокая / низкая (меню паузы); авто снижает качество на слабых устройствах.
- **Без внешних запросов.** Шрифты встроены, звук синтезируется; служебный доступ для тестов только с `?debug`.
- **Корона.** Самая крупная рыба носит корону и видна на мини-карте.
- **Мир.** 12 000 × 3 600, параллакс в три слоя: затонувшие корабли, руины, скелет кита, гигантские раковины.

## Структура

```
src/game.html     исходник игры (фрагмент страницы, так же публикуется артефактом Claude)
index.html        собранная страница для GitHub Pages — не править руками
tools/build.js    сборка: node tools/build.js
docs/BALANCE.md   цифры баланса и итоги автотестов
docs/STORE.md     тексты и требования для площадок
docs/store/       обложки, иконка, скриншоты, ролики для площадок
tools/sim50.js    автоигрок для проверки баланса (Node.js)
tools/simlife.js  выживание в одной жизни
```

Правки вносятся в `src/game.html`, потом `node tools/build.js`.

## Проверка баланса

```
node tools/sim50.js 0.9 2 3600
```

Склонность: `-0.9` — травоядная, `0` — всеядная, `0.9` — хищник. Последние два числа — число забегов и длина забега в секундах игрового времени. Подробнее в `docs/BALANCE.md`.
